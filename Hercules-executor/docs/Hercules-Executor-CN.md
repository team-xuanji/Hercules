# Hercules Executor 模块

## 概述

Hercules Executor 是 Hercules 任务系统的执行引擎，负责从 Hercules Manager 消费任务并使用动态加载的插件执行这些任务。它作为分布式工作组件，提供可扩展的任务处理能力。

## 架构概述

Hercules Executor 采用**无状态、纯 HTTP 架构**进行所有任务管理操作。它通过 RESTful API 与 Hercules Manager 进行独占通信，消除了任务生命周期管理对直接数据库连接的需求。

### 关键架构原则：
- **纯 HTTP 通信**：所有任务操作通过 Feign 客户端使用 RESTful API
- **无状态设计**：任务管理无持久状态或数据库依赖
- **分布式就绪**：专为水平扩展和多实例部署设计
- **基于插件的执行**：动态插件加载与隔离执行环境

### HTTP API 操作：
- `tryFetchTasks`：从管理器轮询可用任务
- `tryLockOneTask`：锁定任务进行独占执行
- `finishOneTask`：报告任务成功完成
- `asyncRerunOneTask`：请求任务重试协调
- `reportExecutorInfo`：报告执行器状态和容量

## 核心功能

### 1. 任务执行引擎

Hercules Executor 通过 `ExecutorProcessHandle` 提供强大的任务执行能力：

#### 功能特性：
- **多线程执行**：基于槽位的容量管理的可配置线程池
- **任务生命周期管理**：从初始化到完成的完整任务状态跟踪
- **基于插件的处理**：动态加载和执行业务特定插件
- **重试机制**：具有可配置尝试次数和退避策略的自动重试

#### 核心组件：
- `ExecutorProcessHandleImpl`：处理任务执行逻辑的核心实现
- `TaskConsumer`：通过 HTTP API 轮询和分发任务的定时服务
- `HerculesManagerApi`：所有任务生命周期操作的 Feign 客户端

### 2. 动态插件加载

支持运行时插件加载和执行的高级插件管理系统：

#### 功能特性：
- **远程插件加载**：从 HTTP/HTTPS 和 OSS 源下载和加载插件
- **插件缓存**：具有自动版本检查和更新的智能缓存
- **类加载器隔离**：具有适当类加载器管理的安全插件执行
- **多协议支持**：针对不同存储系统的灵活下载机制

#### 核心组件：
- `DownloaderManager`：协议特定下载器的集中管理
- `HttpDownloader`/`HttpsDownloader`：基于 HTTP 的插件资源下载器
- `FileStorage`：插件存储操作的抽象层

### 3. 资源管理

全面的资源管理和优化：

#### 功能特性：
- **执行槽位管理**：动态容量监控和分配
- **内存管理**：可配置的内存限制和垃圾收集优化
- **临时文件清理**：自动清理下载的资源和临时文件
- **HTTP 连接池**：高效的 API 通信 HTTP 连接管理

#### 核心组件：
- `RunnerEnv`：环境配置和资源限制
- `Constant`：系统常量和配置值

### 4. 集成层

与 Hercules Manager 和外部系统的无缝集成：

#### 功能特性：
- **Manager API 集成**：与 Hercules Manager 的 RESTful 通信
- **任务状态报告**：实时状态更新和进度报告
- **链式任务支持**：支持任务链和工作流执行
- **异步重试协调**：与管理器的协调重试机制

#### 核心组件：
- `HerculesManagerApi`：管理器通信的 Feign 客户端
- `FeignConfig`：HTTP 客户端配置和错误处理
- `ApiGatewayUtil`：API 网关集成工具

## 架构组件

### 执行流程
1. **任务轮询**：TaskConsumer 通过 HTTP API (`tryFetchTasks`) 定期轮询可用任务
2. **任务锁定**：通过 HTTP API (`tryLockOneTask`) 锁定任务进行执行
3. **插件加载**：动态下载和加载所需插件
4. **任务执行**：在具有适当资源管理的隔离线程池中执行任务
5. **状态报告**：通过 HTTP API (`finishOneTask`) 将执行状态和结果报告回管理器
6. **资源清理**：执行后清理临时资源

### 插件系统
- **插件发现**：使用 ServiceLoader 自动发现插件实现
- **版本管理**：智能插件版本检查和缓存失效
- **资源隔离**：每个插件组维护隔离的资源和依赖项
- **错误处理**：全面的错误处理和恢复机制

### 数据处理集成
- **DuckDB 支持**：用于高级数据处理的可选 DuckDB 集成
- **SQL 执行**：任务上下文中的直接 SQL 执行能力
- **数据管道**：支持复杂的 ETL 和数据转换工作流

## 配置

### 环境变量：
- **EXECUTOR_SLOT_SIZE**：最大并发任务执行槽位
- **BUSINESS_KEY**：任务路由的业务组标识符
- **ENABLE_DUCKDB**：启用/禁用 DuckDB 集成
- **DUCKDB_MEM_GB_SIZE**：DuckDB 内存分配限制
- **DUCKDB_SPILL_GB_SIZE**：DuckDB 磁盘溢出缓冲区大小

### 应用属性：
- **HTTP API 配置**：Hercules Manager API 端点与身份认证
- **文件存储**：插件下载的 OSS/HTTP 配置
- **Feign 客户端**：HTTP 客户端的重试策略、超时与序列化配置
- **可选 DuckDB**：仅用于数据处理的可选数据库配置（非任务管理）
- **日志记录**：支持跟踪 ID 的结构化日志

### 部署配置文件：
- 多环境支持（qa、prod、test）
- 具有资源限制的 Docker 容器化
- Kubernetes 部署配置
- 健康检查和监控端点
